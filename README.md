# 📁 Aulas de C# (Senac)

Repositório dedicado ao armazenamento, organização e evolução dos projetos, exercícios e códigos desenvolvidos durante as aulas da linguagem C#.

## 🎯 Objetivo do Repositório

Este espaço serve como um portfólio pessoal e histórico de aprendizado, focado em dominar os fundamentos da Programação Orientada a Objetos (POO) e a sintaxe do C# utilizando a plataforma .NET.

## 🛠️ Tecnologias e Ferramentas

* **Linguagem:** C#
* **Framework:** .NET Framework / .NET Core
* **IDE:** Visual Studio / VS Code
* **Controle de Versão:** Git e GitHub
